2 · Psychrometrics

Every air-side calculation depends on the state of moist air. Two independent properties plus pressure define the state completely. The engine uses the ASHRAE Hyland–Wexler equations.

p_ws : ln p = C8/T + C9 + C10·T + C11·T² + C12·T³ + C13·ln T W = 0.621945 · p_w / (p − p_w) [kg/kg] h = 1.006·t + W·(2501 + 1.86·t) [kJ/kg] v = 0.287042·(t+273.15)(1+1.607858·W)/p [m³/kg] p = 101.325·(1 − 2.25577e-5·Z)^5.2559 [kPa]

3 · Cooling load (hourly)

Heat gain is not cooling load. The radiant part of each gain is first stored in the building mass and released later, so the load peaks lower and later than the gain. This page runs the same algorithm as cooling_load() over 24 hours.

Sol-air: T_sa = T_o + α·E_t/h_o − ΔR (3.9 K roofs) Conduction: q = U·A·[(T̄_sa − T_i) + f·(T_sa(t−φ) − T̄_sa)] Glass: q = U·A·(T_o−T_i) + A·SHGC·IAC·E_t Load(h) = (1−F_rad)·q(h) + F_rad·Σ r_j·q(h−j) (RTS) Infil.: Q_s = 1.23·V·ΔT Q_l = 3010·V·ΔW (V in L/s)

4 · Air-side process: ventilation, supply air, coil

The room peak sets the supply airflow. ASHRAE 62.1 sets the outdoor air. Mixing outdoor and return air gives the coil entering state, and the required supply state gives the leaving state. Extending that line to saturation gives the ADP.

V_bz = R_p·P_z + R_a·A_z V_oz = V_bz / E_z V_sa = Q_s / (ρ·c_p·(T_r − T_s)) W_s = W_r − Q_l / (ρ·V_sa·2501000) BF = (t_off − ADP)/(t_on − ADP) Q_coil = ṁ·(h_on − h_off)

5 · Duct sizing (equal friction)

Friction is found with Darcy–Weisbach and the Colebrook equation. The method solves the exact diameter for the target friction, rounds it up to a standard size, and converts it to a rectangular duct of equal friction (Huebscher).

6 · Pipe sizing & plant

Water flow comes from the load and the design ΔT. The sizer picks the smallest Sch.40 steel pipe within the friction and velocity limits. The plant is sized on the coincident (block) load.

V̇ = Q / (ρ·c_p·ΔT) 1 kW @ 5.5 K → 0.0434 L/s Q_reject = Q_evap·(1 + 1/COP) P_pump = V̇·Δp / (η_p·η_m) P_fan = V̇·Δp_t / (η_f·η_m·η_d) Affinity: V̇ ∝ n, Δp ∝ n², P ∝ n³

7 · Equipment schedule & bill of materials

This turns the design into items you can buy. Each item gets a quantity and the duty and spec to send to suppliers for quotation. It updates live from sections 3–6. Download the CSV and add unit prices; the amount column calculates in Excel. 8 · Python engine — hvac_engine.py

It uses the Python standard library only (math, dataclasses), so it runs offline. Run python hvac_engine.py to print the full worked example. Import it to use it in your own scripts.

Typical script

from hvac_engine import *
site = Site(21.0, 105.8, 7)
z = Zone("Office", 150, 3.0, people=15)
z.walls.append(Opaque("W", 18, 0.6, 90, 90))
z.windows.append(Window("Wg", 12, 2.8, 0.4, 90))
r  = cooling_load(z, site, 202, 36, 7, 28)
h  = r["peak_hour"]
Qs, Ql = r["sensible"][h], r["latent"][h]
V  = supply_airflow(Qs, 24, 13)
_, Voz = outdoor_air("office", 150, 15)

Algorithm of cooling_load()

  1. Build 24 hourly outdoor states: T = T_DB − f(h)·DR, with W fixed from the MCWB.
  2. For each hour, compute the solar position and the ASHRAE clear-sky beam and diffuse irradiance, then the irradiance on each surface.
  3. Opaque surfaces: sol-air temperature, then the decrement/time-lag conduction profile.
  4. Glass: conduction plus SHGC × irradiance × IAC.
  5. Internal gains × the occupancy schedule.
  6. Split each component into radiant and convective parts, then convolve the radiant part with the radiant time series (24-hour periodic).
  7. Sum the sensible components and add the latent part (people + infiltration). The peak hour is the hour with the maximum total.

Accuracy notes

  • The RTS is a smooth geometric approximation. Replace it with the ASHRAE tabulated factors for certified work.
  • Run several months. In the tropics, south façades can peak outside July.
  • Sizing an AHU or plant needs the hour-by-hour sum across zones (block load), not the sum of zone peaks.
